# CLAUDE.md — Templates por Stack

---

## Que es el CLAUDE.md

El `CLAUDE.md` es el archivo de instrucciones que Claude Code lee automaticamente cada vez que abris un proyecto. Define las reglas, convenciones y arquitectura especificas de TU repositorio. Si no lo conoces, leete primero la [seccion del Handbook](../handbook/setup-skills-claude-md).

---

## Como usar estos templates

Cada template es un punto de partida para tu proyecto. La idea NO es copiar y pegar sin pensar — es que tengas una estructura solida y la adaptes a las convenciones reales de tu equipo.

1. Elegí el template que matchee tu stack
2. Copialo a la raiz de tu repo como `CLAUDE.md`
3. Ajusta las reglas, el stack y la arquitectura a tu proyecto real
4. Iterá — a medida que descubras patrones o reglas nuevas, agregalas

:::tip[Empeza simple]
No intentes cubrir todo en la primera version. Un CLAUDE.md con 10 reglas claras es mejor que uno con 50 reglas genéricas. Anda agregando a medida que trabajes con la IA y veas que necesita mas contexto.
:::
